# LOFT / Ticket Studio

Готовое приложение для выдачи экзаменационных билетов. Тёплый графит, медные акценты, крупная типографика и интерфейс без установки дополнительных компонентов.

![Интерфейс Ticket Studio](docs/preview-main.png)

## Открыть приложение

Готовая сборка находится в `dist/TicketStudio/`: дважды щёлкните **TicketStudio.exe**. В комплекте демонстрационные данные: 3 группы (одна пустая), 7 студентов, 8 билетов. .NET и Microsoft Office для работы приложения не нужны. ОС: Windows 10/11 x64.

Для переноса используйте `dist/TicketStudio-windows-x64.zip`. Сначала распакуйте архив целиком в папку с правом записи, затем запустите EXE. Журнал создаётся в этой же папке.

## Работа

1. Выберите группу, затем студента. Кнопка выдачи станет активной.
2. Нажмите «Сгенерировать билет». Журнал сохранится до показа окна результата.
3. Закройте билет по ESC или кнопкой «Следующий студент».
4. Повторная выдача вернёт номер из первой записи и добавит новую строку с пометкой «да».

В боковой панели можно обновить источники, открыть папку данных и журнал. Если файл занят Excel, закройте его и подтвердите повтор попытки.

## Собственные данные

Замените `students.xlsx` и `tickets.docx` рядом с EXE и нажмите «Обновить источники».

- Excel: каждый лист — группа; заголовки в строке 1; A — фамилия, B — имя, данные со строки 2.
- Word: заголовок `Билет N`, затем минимум 3 нумерованных абзаца. Поддерживается текстовая и автоматическая нумерация Word. Показываются первые 3 вопроса.
- Некорректные и дублирующиеся билеты пропускаются с записью в `tickets-parser.log`.
- Если старый номер студента исчез из Word, выдача приостанавливается с объяснением; восстановите билет и обновите источники.

Пример Word:

```text
Билет 1
1. Что такое алгоритм?
2. Назовите основные свойства алгоритма.
3. Приведите пример алгоритма поиска.
```

`results.xlsx` создаётся при запуске. Колонки: Группа, Фамилия, Имя, Номер билета, Дата и время, Повтор. История дополняется; старые значения и оформление не изменяются. Запись производится через временный файл, чтобы ошибка сериализации не повредила существующий журнал.

## Сборка из исходников

Окружение лабораторной работы: C#, WPF, .NET 10, ClosedXML и Open XML SDK.

```powershell
dotnet run --project src/ExamTicketGenerator
dotnet test tests/ExamTicketGenerator.Tests/ExamTicketGenerator.Tests.csproj
powershell -ExecutionPolicy Bypass -File scripts/build-portable.ps1
```

При запуске из исходников файлы данных нужны в выходной папке рядом с EXE. Скрипт сборки создаёт автономный EXE и примеры данных, не заменяя существующие источники. На GitHub Actions комплект автоматически собирается как артефакт `TicketStudio-windows-x64`.

Проверки: 12 unit-тестов и отдельная проверка WPF (`TicketStudio.exe --verify-ui`). Она проверяет отсутствующие файлы, пустую группу, состояния кнопки, две реальные выдачи, сохранение перед показом результата, повторы и ESC на изолированных данных.

Английское техническое задание для этапа Prompt Engineering: [docs/lab2-prompt-en.md](docs/lab2-prompt-en.md).
