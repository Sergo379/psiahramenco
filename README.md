# Ticket Studio — лабораторная работа №2

Десктопное WPF-приложение на C# для выдачи экзаменационных билетов. Интерфейс выполнен в тёмной карточной стилистике: группа и студент выбираются из выпадающих списков, а результат появляется в отдельном окне.

## Что реализовано

- `students.xlsx`: каждый лист — группа, строки со 2-й — фамилия и имя студента.
- `tickets.docx`: заголовки `Билет N` и нумерованные вопросы; используются билеты минимум с тремя вопросами.
- `results.xlsx`: журнал A–F (`Группа`, `Фамилия`, `Имя`, `Номер билета`, `Дата и время`, `Повтор`). Создаётся автоматически и дополняется без перезаписи истории.
- повторная выдача того же студента находит номер из первой записи и добавляет новую строку с `да` в колонке «Повтор».
- пропущенные или некорректные билеты записываются в `tickets-parser.log`.
- отсутствие входных файлов и занятый `results.xlsx` обрабатываются понятными сообщениями без падения приложения.
- `ESC` закрывает окно билета и возвращает приложение к следующему выбору.

## Запуск

Требуется Windows и .NET 10 SDK. Положите рядом с исполняемым файлом (или запустите из папки проекта) `students.xlsx` и `tickets.docx`.

```powershell
dotnet restore
dotnet run --project src/ExamTicketGenerator
```

## Тесты

```powershell
dotnet test tests/ExamTicketGenerator.Tests/ExamTicketGenerator.Tests.csproj
```

Тесты проверяют чтение групп и студентов, разбор корректного/некорректного билета и идемпотентность номера при повторной выдаче.

## Структура входного Word-файла

```text
Билет 1
1. Вопрос первый
2. Вопрос второй
3. Вопрос третий
```
