LOFT / TICKET STUDIO

ЗАПУСК
Дважды щёлкните TicketStudio.exe. Установка .NET не нужна.
Приложение рассчитано на Windows 10/11 x64.
При первом запуске Windows может предупредить о неизвестном издателе:
сборка локальная и не имеет платной цифровой подписи.

В комплекте демонстрационные группы и 8 билетов по программированию.
Для работы с реальными данными замените students.xlsx и tickets.docx,
после чего нажмите «Обновить источники».

students.xlsx: каждый лист — группа; A1 = Фамилия, B1 = Имя;
фамилии и имена идут в колонках A и B начиная со строки 2.

tickets.docx: заголовок «Билет N», затем три нумерованных абзаца:
1. Первый вопрос
2. Второй вопрос
3. Третий вопрос
Допускается автоматическая нумерация Word.

Выберите группу, затем студента и нажмите «Сгенерировать билет».
Результат сразу сохраняется в results.xlsx рядом с приложением.
ESC закрывает окно билета. Можно сразу выбрать следующего студента.
Повторная выдача сохраняет номер из первой записи и добавляет строку
с пометкой «да». Старые записи не заменяются.

Если Excel блокирует журнал, закройте файл и повторите попытку.
Если билет из первой записи удалён из Word, восстановите его.
Ошибки разбора Word записываются в tickets-parser.log.

Храните папку приложения в доступном для записи месте, например
Документы или Рабочий стол. Сохраняйте вместе EXE и оба входных файла.
Перед переносом папки закройте приложение и Excel.
